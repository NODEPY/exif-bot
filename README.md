## Що вміє бот

Надішли зображення — бот поверне технічний звіт, короткий опис і кнопки для роботи з файлом. Для збереження EXIF надсилай фото **як файл без стиснення**.

| Функція | Що отримуєш |
|---|---|
| **Камера та EXIF** | Виробник, модель, об’єктив, дата, ISO, витримка, діафрагма, фокусна відстань, автор і copyright — якщо вони є у файлі |
| **GPS** | Координати з метаданих і посилання на Google Maps |
| **Опис зображення** | Локальна модель BLIP формує опис англійською; Marian перекладає українською або російською |
| **Технічні характеристики** | Розміри, формат, співвідношення сторін, яскравість, контраст, оцінка різкості й ентропія |
| **Хеші** | SHA-256 отриманих байтів та візуальний aHash |
| **Очищення** | Нова JPEG-копія без переданих EXIF-метаданих |
| **Авторський підпис** | Запис імені автора в Artist і Copyright нової JPEG-копії |
| **Прев’ю** | Зображення з фотографією та основними характеристиками |

Інтерфейс і описи підтримують **українську, англійську та російську**. Частина технічних підписів і службових помилок залишається англійською.

## Запуск

Потрібні Python, доступ до Telegram та інтернет для першого завантаження моделей. **macOS і Linux** підтримуються кодом; на Windows потрібне середовище **WSL**, оскільки блокування другого екземпляра використовує `fcntl`.

### 1. Завантаж проєкт

```sh
git clone https://github.com/NODEPY/exif-bot.git
cd exif-bot
```

### 2. Створи середовище та встанови залежності

```sh
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Локальне середовище автора: **Python 3.14**, aiogram 3, Pillow, PyTorch та Transformers. Доступність пакетів PyTorch залежить від платформи й версії Python. Це не інсталятор із вбудованими моделями: перше встановлення може зайняти час і потребує місця на диску.

### 3. Додай токен

Створи бота через [@BotFather](https://t.me/BotFather), потім:

```sh
cp .env.example .env
```

Відкрий `.env` у редакторі та заміни значення `BOT_TOKEN` власним токеном. Файл `.env` не повинен потрапляти в GitHub.

### 4. Запусти

```sh
python bot.py
```

На macOS також можна виконати `zsh start_bot.command` із папки проєкту. Скрипт використовує середовище `venv` поруч із `bot.py`.

Відкрий свого бота в Telegram → **/start** → вибери мову → надішли фотографію як файл. Зупинка у терміналі: **Ctrl+C**.

## Моделі та обчислення

| Завдання | Модель |
|---|---|
| Опис зображення | [`Salesforce/blip-image-captioning-base`](https://huggingface.co/Salesforce/blip-image-captioning-base) |
| EN → UK | [`Helsinki-NLP/opus-mt-en-uk`](https://huggingface.co/Helsinki-NLP/opus-mt-en-uk) |
| EN → RU | [`Helsinki-NLP/opus-mt-en-ru`](https://huggingface.co/Helsinki-NLP/opus-mt-en-ru) |

BLIP завантажується під час запуску. Перекладач завантажується за першої потреби у відповідній мові. Для опису автоматично обирається **Apple MPS → NVIDIA CUDA → CPU**; переклад працює на CPU. `sentencepiece` і `sacremoses` включені для токенізаторів перекладу.

Моделі мають власні умови використання. Посилання вище ведуть до їхніх сторінок.

## Що варто знати

- **EXIF може бути відсутній.** Telegram часто видаляє його під час надсилання фотографії зі стисненням. GPS не визначається за виглядом фото — береться лише з метаданих.
- **Опис може помилятися.** BLIP не встановлює достовірність вмісту, а технічні показники не доводять, що фото справжнє або відредаговане.
- **Очищення створює новий JPEG.** Файл перекодовується, прозорість втрачається. Оригінал у Telegram не змінюється.
- **Copyright — поле метаданих.** Це не підтвердження авторства. Поточна версія записує рік `2026`.
- **Аналізи тимчасові.** У пам’яті зберігаються до п’яти останніх аналізів для кожного користувача. Після перезапуску кнопки старих звітів стають недоступними.
- **Один процес на папку.** Файл `.bot.lock` захищає від випадкового подвійного запуску.

## Приватність

Це **Telegram-бот**, а не автономний аналізатор: фото проходять через Telegram і надходять на комп’ютер, де запущено бота. Моделі виконують обчислення на цьому комп’ютері; окремий хмарний сервіс розпізнавання не викликається.

Код зберігає робочі JPEG-копії в пам’яті та друкує згенеровані описи в консоль. Перехід за кнопкою Google Maps відкриває координати у Google. [Докладніше →](docs/PRIVACY.md)

У репозиторії немає робочого токена, `.env`, фотографій, кешів моделей або особистого віртуального середовища.

## Структура

```text
bot.py                 Telegram-обробники, аналіз, опис і переклад
requirements.txt       Залежності
.env.example           Приклад конфігурації без секретів
start_bot.command      Запуск на macOS
docs/                  Інструкції та обробка даних
.github/workflows/     Автоматична перевірка синтаксису
```

Перед публікацією перевірено синтаксис Python та відсутність токенів у файлах релізу. Повний запуск бота й завантаження моделей під час оформлення репозиторію не виконувалися. Для повідомлення про помилку додай кроки відтворення й знеособлений приклад; токен надсилати не потрібно.
